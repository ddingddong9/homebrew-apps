# ddingddong9/homebrew-apps

Homebrew tap for [GitMorning](https://github.com/ddingddong9/gitmorning), a macOS app for exploring GitHub Trending.

```sh
brew install --cask ddingddong9/apps/gitmorning
```

Homebrew taps and trusts this cask on the first install. The cask is updated automatically from each published GitMorning release; please open issues and pull requests in [ddingddong9/gitmorning](https://github.com/ddingddong9/gitmorning).
